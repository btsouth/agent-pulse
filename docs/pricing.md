# Pricing policy

API value uses token categories and the price snapshot shipped with this version. The bundled LiteLLM subset contains OpenAI, Anthropic, and Gemini entries and the price fields consumed by the collector. Its source revision, URL, and retrieval time are embedded in `catalog.json`.

The OpenCode Go model overrides are kept separately in `pricing.json`: the documented price table for the Go model list, with its source and verification date. DeepSeek entries carry peak windows (01:00-04:00 and 06:00-10:00 UTC, Monday through Friday) whose rates double during those hours; the collector prices each record by its timestamp. Each entry also carries the documented monthly usage limit, used for the Go card's per-model allowance view; DeepSeek V4.1 Flash carries the $60 limit the docs now list, with no promo window outstanding. An explicit zero rate marks a free model and is distinct from a missing price. Matching is exact or uses the provider-prefixed catalog key. There is no guessed price for an unknown model.

Codex model rates live in `codex-pricing.json`. GPT-6 Sol and Luna use [OpenAI's published Standard rates](https://developers.openai.com/api/docs/pricing), including the long-context tier above 272K input tokens. [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol) uses $2 input, $0.10 cached input, $2.50 cache writes, and $10 output per million tokens, checked September 29, 2026. Above 272K input tokens, its input and cache rates double and output is $15 per million tokens for the full request. `gpt-5.3-codex-spark` uses the published openai entry from the model catalog OpenCode consumes. `codex-auto-review` has no published rate, so it is marked `internal`: its tokens count as processed usage, its API value is zero, and it no longer appears in the missing-price warning. Internal is distinct from both a published zero rate and a missing rate.

Codex speed tiers. OpenAI bills Fast mode (the `priority` service tier) at 2x the applicable Standard rate, long-context rates included, and Flex at 50%, per the [pricing page](https://developers.openai.com/api/docs/pricing) checked October 3, 2026. `codex-pricing.json` carries those rates under the catalog's `_priority` and `_flex` key suffixes, which the LiteLLM snapshot already uses for other OpenAI models. Each Codex rollout logs a `thread_settings_applied` snapshot whose `service_tier` is the speed requested for the turns that follow, and the ledger stores it per request as `requestedServiceTier`. A tier change logged after a turn has produced usage leaves the rest of that turn unknown, because it may only apply from the next turn. Codex does not record the tier the server actually used, so `serviceTier` stays empty for Codex; when a source does record it, the served tier takes precedence, since a downgraded Fast request is billed at Standard. Codex also logs no snapshot before a thread's first turn, and history recorded before these snapshots existed has none. Records with no recorded tier are valued at Standard rates and counted separately, so the dashboard can say how much of the estimate rests on that assumption. A recorded tier with no published rate for its model leaves the record unpriced rather than borrowing the Standard rate. Codex subscription allowance multipliers are a separate quota measure and never enter API value. A ledger created before this change re-reads its Codex rollouts once to recover recorded tiers; events whose transcript is gone keep an unknown tier.

Direct Claude Opus 5.5, Sonnet 5.5, and Haiku 5.5 rates live in `claude-pricing.json`, from [Claude's pricing page](https://platform.claude.com/docs/en/about-claude/pricing). The five-minute and one-hour cache writes use their separate published rates. Sonnet 5.5 cache reads are $0.10 per million, half the earlier rate. Haiku 5.5 is priced by prompt length: a request whose input, cache reads, and cache writes add up to more than 100,000 tokens is valued at the higher rates for every category, including its output.

Muse Spark 1.3 rates live in `muse-pricing.json` with their documentation source and verification date: per million tokens, Standard input $1.25, output $4.25, cached input $0.15; Contributor input $0.10, output $0.20, cached input $0.002. Muse records no per-request cost estimate, so unlike Grok there is no recorded figure to take precedence; catalog rates are the only source. This is the API-equivalent value, not subscription spending. No cache-write rate is published, so records with nonzero cache writes stay unpriced; Muse reasoning is recorded separately and excluded from value, as with Codex and Grok.

Antigravity has no bundled rate table. Its records are priced only where the served model string exactly matches an existing catalog entry; the suffixed ids it records (`-n`, `-high`, `-medium`) normally do not, so those tokens stay unpriced rather than being trimmed back to a base model and charged a rate that was never billed. Thinking is included in output and priced once, and the separate reasoning counter is not added again, as with Gemini. There is no cache-write count, so cache writes never affect its pricing.

Grok Build uses `usage.costUsdTicks` from completed turns, divided by 10 billion to obtain USD. Per-model values take precedence; an aggregate value is used only for a single-model turn. Missing or zero ticks remain unpriced, even if a similarly named catalog model exists. This is Grok’s API-equivalent estimate, not subscription spending. Cache savings cannot be derived from this figure and are excluded from known cache savings.

A catalog-priced record is unpriced if any nonzero token category lacks an applicable rate. Its tokens remain counted, its estimated value is omitted, and the UI identifies incomplete pricing. A catalog's explicit zero rate is distinct from a missing rate.

Cache reads and cache writes use their respective rates. Claude's one-hour write counter is a subset of cache writes, and is charged separately when reported. Context-tier thresholds are applied only where the catalog defines them. Reasoning is not added again to Codex or Grok output; OpenCode's separate reasoning counter is included in output.

OpenCode, Pi, and Oh My Pi use a positive API estimate recorded by the app when present. Zero or missing recorded costs fall back to exact catalog matches; they are not assumed to mean free usage. OpenCode Go prefers its catalog rates, including peak-hour pricing, and falls back to the app's recorded per-message estimate when the catalog has no usable rate for the model. Gemini output includes its separate thinking count. Pi reasoning is already included in output. These app estimates are not invoices and do not establish remaining subscription allowance.

Hermes rows price the same way OpenCode Go rows do: catalog rates for the route, with no app estimate to fall back on, since the agent stores none for these routes. A model with no catalog entry stays unpriced, which is why an unpriced-token warning on Ollama Cloud, CommandCode, or ClinePass means the rate table has not caught up with a newly released model, not that the usage is free.

Ollama Cloud rates live in `ollama-pricing.json`, transcribed from the published pricing table with its source and verification date. Every key is namespaced `ollama-cloud/<model>`, because the cloud models share names with the direct providers: an unnamespaced `glm-5.3-flash` entry would price OpenCode Go or Pi traffic at cloud rates. Peak pricing doubles the listed rates between 12:00 and 18:00 UTC, Monday to Friday, and the published table gives peak figures for the DeepSeek models only, so only those entries carry a multiplier. Three models in the table list no cached-input price; records with cache reads against them stay unpriced rather than assuming caching is free.

CommandCode rates live in `commandcode-pricing.json`, transcribed from the rates its own models page publishes. These are the resale rates CommandCode bills against plan credits, which are not always the labs' list prices for the same model, so the file is namespaced `commandcode/<api model id>` and both of its routes read those keys rather than falling through to a lab rate. The table includes GPT-6 Sol and Luna, Claude Opus 5.5, MiMo V2.6 Flash, Pro, and Pro UltraSpeed, and DeepSeek V4.1 Flash Fast, whose rates table gives $0.16 input, $0.58 output, and $0.016 cache read per million, doubling in the peak bands. Peak pricing doubles the listed rates between 01:00-04:00 and 06:00-10:00 UTC on weekdays, and only the DeepSeek entries carry a multiplier because those are the only ones it publishes peak figures for. Models that are free while capacity lasts carry zero rates rather than staying unpriced, so their tokens are not reported as an unknown cost.

ClinePass rates live in `clinepass-pricing.json`, transcribed from the reference pricing table in Cline's own documentation. ClinePass is a flat monthly subscription, so these figures are API-equivalent values for the tokens the ledger recorded, never a bill; they are what makes the card's value against a subscription price comparable with the other providers. Every key is namespaced `clinepass/cline-pass/<model id>`: the vendor prefix is part of the model id the API returns, so no bare name is stored. Rows whose wire provider is `cline-pass` use that same ClinePass table. Peak pricing doubles the listed rates between 01:00-04:00 and 06:00-10:00 UTC on weekdays, and only the DeepSeek entries carry a multiplier. `cline-pass/deepseek-v4.1-flash` is missing from Cline's own model table, so it carries DeepSeek's published Flash rate, which DeepSeek documents as the rate that name is billed at. The same model also arrives as `deepseek/deepseek-v4.1-flash`, because a client writes the id with the model vendor's prefix instead of Cline's; both shapes carry the route's rate, and a row whose id lost the prefix entirely stays unpriced rather than borrowing another route's rate. Cline lists no cached-write rate for any model but the three Qwen entries, so records with cache writes against the others stay unpriced rather than assuming free writes.

User override: place a JSON object containing `source`, optional `fetchedAtMs`, and a `document` map in `$XDG_STATE_HOME/omarchy/ai-usage/rates.json`. User entries override matching bundled and official entries; other bundled models remain available. The documented provider overrides apply underneath the user catalog. Delete the override to return to the bundled snapshot. The app does not download catalog updates automatically.

Maintainers refresh the bundled snapshot with `python3 tools/update_catalog.py <commit sha>`. It keeps an entry that upstream has dropped, because local history still holds that model's tokens and a dropped rate would turn already recorded usage into unpriced tokens long after the fact; `--drop-removed` mirrors upstream instead. It prints what it added and which base rates changed, and every run is a review diff. `python3 tools/update_go_pricing.py --write` regenerates the Go table from the OpenCode Go documentation table, and its `--check` exits non-zero when that table has moved. `python3 tools/pricing_gaps.py` lists every model in the local ledger with no applicable rate, names the table that owns its route and the step that refreshes it, and reports only the sources the dashboard counts unless `--all-providers` asks for the whole ledger. Pass `--check` for a timer, which exits non-zero when the list is not empty, so a new model is reported instead of a person finding one on a dashboard. The CommandCode, ClinePass, Ollama Cloud, and Muse tables are still transcribed by hand from their own published pages. Review price changes and upstream licensing before release. The Go, Muse, and Codex overrides are reviewed against their own documented sources.

Grok completed turns can contain many model calls. The dashboard labels aggregated message/turn rows as usage records and shows Grok model calls separately. They are not interchangeable request counts.

Gemini 3.8 Flash standard rates were checked against [Google’s pricing page](https://ai.google.dev/gemini-api/docs/pricing) on September 5, 2026: $0.75 input, $3.75 output, and $0.075 cache reads per million tokens. These promotional rates end December 31, 2026. Cache storage, grounding tools, and service-tier premiums are not calculated from local token categories. Other snapshot entries are attributed catalog data, not a claim that every rate was independently verified.

Cursor retains cloud events with zero reported tokens and an explicit zero list-price value. They count as usage records, not model requests. Its `turns` counter is included in report buckets for clients, although the dashboard does not display it separately. Missing conversation ids share a `cloud` session, so Cursor session averages are approximate.

The Go model allowance view follows account and drilldown filters. Its window is estimated as the 30 days preceding the reported monthly reset, or from the first of the local calendar month when no reset is available. It is not an exact provider billing reconciliation.
