Local token ledger

Today by hour, plus 7 / 30 / 90 day and yearly views. Input, output, cache, and estimated API value. Sources appear when they have history.

Named accounts

Label folders as Local or Work. Copied sessions count once. Conflicting labels are flagged. Labels are not logins.

Bar widget

A live local token count, recent hourly usage, and source limits in the Omarchy bar. Open analytics from the panel or the application menu.

How it works

The installer copies the app into your home directory. It never writes to /usr/share/omarchy and does not need sudo.

01

Scan local history

Codex, Claude, Grok Build, Gemini CLI, OpenCode, Pi, Oh My Pi, and Muse folders already on disk.

02

Keep a metric ledger

Counters, model names, project paths, session IDs, timestamps. Conversation bodies and credentials stay in their apps.

03

Price what you can

Catalog rates or the app’s recorded estimate. Missing prices stay marked unpriced. This is not your bill.

04

Refresh on a timer

While open, Agent Pulse checks local histories every 15 seconds and counts usage as agents record it. Full scans and provider limits keep their usual schedule.

The screens

Every still is the real Quickshell UI, captured from the demo instance. The subtitle in the window says so.

Hourly activity

Today starts with exact hourly token totals and source segments. Select an hour to inspect its recorded sessions. Cache reuse is counted on every request.

  • Local clock hours in the bar clock's 12- or 24-hour format, with daylight saving hours distinguished
  • Source, account, and model filters
  • Session totals without request times shown separately

Inspect an hour

Select a bar to scope the summary, source comparison, and session list to that hour. Back returns to the previous view.

  • Exact token counts on every hour
  • One click to the sessions behind the total
  • Clear labels for usage that has no exact hour

Sources and accounts

Compare each source and account in one compact list. Open limits and models when you need more detail. Account-filtered views hide current-login quota.

  • Tokens and estimated API value side by side
  • Current-login limits in the expanded detail
  • Unpriced tokens remain visible

Account filter

Filter the whole page to Work or Local, including hourly activity and the breakdown table. Folders must already be mounted.

  • Stable event IDs deduplicate copies
  • Conflicts land in Needs review
  • History labels are not verified identities

Settings

Sources, accounts, pricing, sync, and appearance have separate settings tabs. Set optional monthly plan prices and point at extra history folders.

  • Local account name plus extra named accounts
  • Window opacity preview before save
  • Optional quota keys stay masked in the UI

Bar widget

The plugin panel shows the latest six local hours across all visible sources or a selected source. Its limit summary shows usage and reset times; each row opens the source's full detail.

  • Open analytics launches the full dashboard
  • One source picker replaces a growing row of provider buttons
  • Install with --with-plugin, then drop the built-in Agents widget if you want a single icon

Processed tokens include cached input reused on each request. API value is an estimate, not a subscription bill. Usage without a request timestamp stays in the day total and is labelled separately from the hourly bars.

Rates are bundled for offline estimates, with provider-specific tables and attributed sources. Recorded Codex Fast requests use Fast API rates; missing speed evidence uses Standard rates and is labelled. API value is separate from subscription charges. Install

Omarchy 4, Quickshell, Python 3.11+, systemd user session. Older Waybar setups are not supported.

Dashboard + bar widget

# from a clone of this repo
git clone https://github.com/btsouth/omarchy-usage-dashboard.git
cd omarchy-usage-dashboard
python3 install.py --with-plugin

Dashboard only

python3 install.py
~/.local/bin/omarchy-usage-dashboard

If the new icon does not appear: omarchy-shell shell rescanPlugins. To use it instead of Agents, remove Agents from the bar layout after install. Uninstall with python3 install.py --uninstall after quitting the dashboard (Ctrl+Q). History and preferences remain. Details: installation, accounts, pricing.
